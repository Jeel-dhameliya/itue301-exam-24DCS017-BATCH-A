# ITUE301 Advanced Web Development Frameworks Open-Book Practical Examination
## SET B: Library Book Management System

### Project Structure
- `/frontend` - React application (Vite)
- `/backend` - Express.js API
- `/.env.example` - Environment variables template

### Scripts
- `npm run dev` in frontend starts the Vite dev server
- `node server.js` or `npm start` in backend starts the Express server
